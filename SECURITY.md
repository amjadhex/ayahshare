# Security policy

Please report vulnerabilities privately by email to **info@eventhex.ai** (subject: "AyahShare security"), or through
GitHub's private vulnerability reporting on this repository. Do not open a public issue.

Include what is affected (web app, API, admin, mobile app), how to reproduce it and the impact you expect. We will
acknowledge your report within a few days and keep you updated until it is fixed.

Only the latest version of `main` (deployed at ayahshare.com) and the latest store versions of the apps are supported.
